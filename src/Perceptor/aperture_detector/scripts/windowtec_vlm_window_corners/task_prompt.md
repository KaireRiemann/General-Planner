请找出图片中所有清晰可见的建筑窗户，并为每一扇窗输出窗户外框的四个角点。

标注规则：
- 只标注真正的窗户，不标注门或玻璃门；
- 不要把百叶窗、窗帘、墙面装饰、屋檐、栏杆或屋顶结构当成窗户；
- 同一个连续的窗户外框只输出一个目标，即使内部有多个窗格或窗扇；
- 只使用图像中实际看得到的窗户外框边缘与边缘交点，不要根据建筑常识、对称性或延长线猜测不可见角点；
- 透视或轻微倾斜的窗户必须按实际可见边缘输出四边形，不要为了规整而改成水平或垂直矩形；
- 点必须贴近窗户外框，不能把外侧百叶、遮阳板、墙面或窗台包含进去；
- 被树木、阴影或其他物体严重遮挡，无法可靠确认四个外框角点时跳过；
- 如果窗户在边缘但四个角仍然可见，可以输出；
- 不要输出同一扇窗的重复框。

只输出四角点几何框，不输出置信度、可见性、备注、类别或编号等额外信息。
